# Sales Performance Analysis

## Overview

An illustrative sales performance analysis model designed to help management understand sales trends, performance against targets, and key business drivers.

## Purpose

The analysis helps management evaluate:

* Sales performance
* Actual vs Target
* Sales variances
* Monthly trends
* Store or business-unit performance
* Key sales drivers

## Key Features

* Sales performance dashboard
* Actual vs Target analysis
* Variance analysis
* Monthly sales trends
* Performance comparison
* Management reporting

## FP&A Skills Demonstrated

* Sales Analysis
* Commercial FP&A
* Variance Analysis
* KPI Analysis
* Performance Management
* Management Reporting

## Tools Used

* Microsoft Excel
* Pivot Tables
* Excel formulas
* Charts
* Data analysis
