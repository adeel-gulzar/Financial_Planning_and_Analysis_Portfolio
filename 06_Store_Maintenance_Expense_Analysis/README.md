# Store Maintenance Expense Analysis

## Overview

An FP&A cost analysis model designed to analyze store maintenance expenditure and identify significant cost drivers and potential savings opportunities.

## Purpose

The analysis helps management evaluate:

* Maintenance expenditure
* Store-level maintenance costs
* Budget vs Actual
* Cost variances
* High-cost locations
* Spending trends
* Potential cost-saving opportunities

## Key Features

* Store-level cost analysis
* Budget vs Actual comparison
* Variance analysis
* Cost trend analysis
* High-cost store identification
* Management reporting

## FP&A Skills Demonstrated

* OPEX Analysis
* Cost Management
* Variance Analysis
* Retail FP&A
* Cost Optimization
* Business Partnering

## Tools Used

* Microsoft Excel
* Pivot Tables
* Excel formulas
* Data analysis
* Charts and reporting

## Data Disclaimer

This is an illustrative portfolio project using simulated/anonymized data. No confidential employer or client information is included.
