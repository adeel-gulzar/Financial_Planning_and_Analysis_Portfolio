# IT Projects CAPEX Tracker

## Overview

An FP&A CAPEX tracking model designed to monitor the financial performance of IT projects from approved budget through actual expenditure.

## Purpose

The tracker helps management monitor:

* Approved project budgets
* Actual CAPEX spending
* Budget utilization
* Project-level variances
* Remaining available budget
* Project financial performance

## Key Features

* Project-level CAPEX tracking
* Budget vs Actual analysis
* Variance analysis
* Budget utilization monitoring
* Project portfolio overview
* Financial control and monitoring

## FP&A Skills Demonstrated

* CAPEX Planning
* Budget Management
* Budget vs Actual Analysis
* Variance Analysis
* Project Financial Management
* Financial Business Partnering

## Tools Used

* Microsoft Excel
* Financial modeling
* Pivot Tables
* Excel formulas
* Management reporting

## Data Disclaimer

This is an illustrative portfolio project using simulated/anonymized data. No confidential employer or client information is included.
