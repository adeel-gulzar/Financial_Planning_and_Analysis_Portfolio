# Stores Executive Dashboard

## Overview

An illustrative retail FP&A dashboard designed to provide management with a consolidated view of store performance and key financial and operational KPIs.

## Purpose

The dashboard helps management monitor:

* Store sales performance
* Gross margin
* Store profitability
* Operating expenses
* Store-level KPIs
* Performance trends
* Variances and key business drivers

## Key Features

* Executive-level store dashboard
* Store performance analysis
* KPI monitoring
* Trend analysis
* Variance analysis
* Management-friendly visualizations
* Interactive Excel reporting

## FP&A Skills Demonstrated

* Financial Planning & Analysis
* Retail FP&A
* KPI Analysis
* Store Performance Analysis
* Variance Analysis
* Management Reporting
* Business Partnering

## Tools Used

* Microsoft Excel
* Pivot Tables
* Excel formulas
* Charts
* Dashboard development
* Data analysis
