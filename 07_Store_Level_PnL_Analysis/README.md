# Store-Level P&L Analysis

## Overview

An illustrative retail FP&A model designed to analyze store-level Profit & Loss performance and identify the key drivers of profitability.

## Purpose

The model helps management evaluate:

* Store revenue
* Gross profit
* Operating expenses
* Store EBITDA/profitability
* Budget vs Actual
* Store-level variances
* Key profitability drivers

## Key Features

* Store-level P&L
* Revenue and gross margin analysis
* OPEX analysis
* Profitability analysis
* Budget vs Actual comparison
* Variance analysis
* Store performance comparison

## FP&A Skills Demonstrated

* Store P&L Analysis
* Retail FP&A
* Profitability Analysis
* Budget vs Actual
* Variance Analysis
* OPEX Management
* Business Partnering

## Tools Used

* Microsoft Excel
