# Store P&L Executive Summary

## Overview

An illustrative executive-level P&L summary designed to provide management with a consolidated view of financial performance across a retail store network.

## Purpose

The summary helps management monitor:

* Total sales
* Gross profit and margin
* Operating expenses
* Store profitability
* Budget vs Actual
* Key financial variances
* Overall store network performance

## Key Features

* Executive P&L summary
* Store network performance
* Revenue and margin analysis
* OPEX analysis
* Profitability analysis
* Budget vs Actual
* Variance analysis
* Management-friendly reporting
