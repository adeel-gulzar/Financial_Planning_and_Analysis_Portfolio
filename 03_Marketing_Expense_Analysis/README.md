# Marketing Expense Analysis

## Overview

An FP&A expense analysis model designed to provide management with visibility into marketing spending and identify significant budget variances.

## Purpose

The analysis helps management evaluate:

* Marketing expenditure
* Budget vs Actual spending
* Expense categories
* Variance and variance %
* Spending trends
* Areas requiring management attention

## Key Features

* Marketing expense analysis
* Budget vs Actual comparison
* Variance analysis
* Expense categorization
* Spending trend analysis
* Management reporting

## FP&A Skills Demonstrated

* OPEX Analysis
* Budget vs Actual Analysis
* Variance Analysis
* Expense Management
* Financial Planning & Analysis
* Business Partnering

## Tools Used

* Microsoft Excel
* Pivot Tables
* Excel formulas
* Data analysis
* Charts and reporting

## Data Disclaimer

This is an illustrative portfolio project using simulated/anonymized data. No confidential employer or client information is included.
