# Balance Sheet & Cash Flow Analysis

## Overview

An illustrative financial analysis model combining Balance Sheet and Cash Flow information to provide management with visibility into financial position, liquidity, and cash movements.

## Purpose

The model helps management analyze:

* Assets and liabilities
* Equity position
* Cash inflows and outflows
* Operating, investing, and financing activities
* Changes in working capital
* Overall liquidity position

## Key Features

* Balance Sheet analysis
* Cash Flow analysis
* Working capital review
* Cash movement analysis
* Management-friendly financial reporting

## FP&A Skills Demonstrated

* Financial Statement Analysis
* Cash Flow Analysis
* Working Capital Analysis
* Management Reporting
* Financial Planning & Analysis

## Tools Used

* Microsoft Excel
* Financial modeling
* Excel formulas
* Financial statement analysis

## Data Disclaimer

This is an illustrative portfolio project using simulated/anonymized data. No confidential employer or client information is included.
